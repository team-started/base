# Breaking Changes v5.0.0 - EXT:starter

## Interne Umbenennung des Inhaltselements "Download"

- Ticket [#53](https://gitlab.com/starterteam/team/base/-/issues/53)

### Beschreibung

Das Inhaltselement "Download" hat einen neuen CType erhalten - `starter_m27_download`, zuvor war
dieser `starter_download`. Ein UpgradeWizard kümmert sich um die Umstellung vorhandener Inhaltselement, jedoch muss
der CType innerhalb von TypoScript, sofern eigene Konfigurationen vorhanden sind, manuel angepasst werden.

## Bild für Navigation entfernt

### Beschreibung

Für eine spezielle Navigation mit Bild, konnte in den Seiteneigenschaften ein entsprechendes Bild (Asset) gepflegt
werden. Aufgrund fehlender Templates für eine solche Navigation, wurde das Feld "Bild für Navigation" (tx_starter_nav_media)
entfernt.

## Drilldown menu entfernt

### Beschreibung

Das Drilldown Menü wurde, wenn implementiert, unterhalb des Footers angezeigt. Aus Mangel an Anwendungsfällen und zur
Reduzierung der Wartung, wurden die Templates entfernt.

## Option um Mediadateien auf bestimmten BreakPoints anzeigen zu lassen entfernt

### Beschreibung

Beim Einbinden von Mediadateien gab es die Optionen "Zeige auf Smartphone", "Zeige auf Tablet" und "Zeige auf Desktop".
Aus Mangel an Anwendungsfällen und zur Reduzierung der Wartung, wurden diese Optionen entfernt.

## Zusätzliche Mediadateien und Einstelloptionen nach BreakPoint entfernt

### Beschreibung

Zusätzliche Bilder nach Breakpoint und die Optionen welche Abstand diese zum Text haben sollen, wurden aus Mangel an
Anwendungsfällen und zur Reduzierung der Wartung entfernt.
